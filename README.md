# 동영상 편집기

대본을 음성으로 바꾸고(TTS), 문장마다 장면을 붙여 영상을 만들고, 음성·자막을 합성해 MP4로 저장하는 데스크톱 프로그램입니다.
창 하나에 탭이 세 개 있습니다.

- **① 음성 만들기**: 인터넷 없이 글을 음성(MP3/WAV)과 자막(SRT)으로 만듭니다. 음성 엔진은 [Supertonic-3](https://github.com/supertone-inc/supertonic)(기본 목소리 10개와 섞어 만든 내 목소리), [MeloTTS](https://github.com/myshell-ai/MeloTTS) 한국어 두 가지입니다.
- **② 영상 만들기**: 이미지·영상 클립·글자 화면을 장면으로 이어 영상을 만듭니다. 장면 길이는 음성의 문장에 맞춰 자동으로 정해집니다.
- **③ 영상-음성-자막 합성하기**: 영상에 음성과 자막을 입힙니다.

> 음성 기능은 `79_TTS`(2026-10-20 기준)에서 가져왔습니다. 이후 수정은 이 폴더에서만 합니다.

## 설치와 실행

- **이 PC**: `run.bat`을 더블클릭하세요. 설치는 이미 끝나 있습니다.
- **다른 PC (exe 버전, 추천)**: Python도 인터넷도 필요 없습니다.
  1. `dist\동영상편집기.zip`을 다른 PC로 옮겨 원하는 곳에 풉니다(바탕화면, 문서 폴더 등).
  2. 폴더 안의 `동영상편집기.exe`를 더블클릭합니다.
  - 설정·작업 파일은 exe 옆에 저장됩니다. `Program Files`처럼 쓸 수 없는 곳에 두면 `%LOCALAPPDATA%\동영상편집기`에 저장됩니다.
  - 같은 폴더의 `movie-cli.exe`(합성), `tts-cli.exe`(음성 만들기)는 명령줄 도구이고, `movie-mcp.exe`는 Claude에 연결하는 MCP 서버입니다(아래 "Claude에서 쓰기"). 아래 "명령줄"에서 `.venv\Scripts\python cli.py` 대신 `movie-cli.exe`, `tts_cli.py` 대신 `tts-cli.exe`를 쓰면 됩니다.
  - 인터넷에서 받은 zip이면 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다(서명하지 않은 프로그램). **추가 정보 → 실행**을 누르세요.
  - "DLL을 불러올 수 없다"는 오류가 나면 Microsoft Visual C++ 재배포 패키지를 설치하세요.
- **다른 PC (소스 그대로)**: [Python 3.12](https://www.python.org/downloads/)를 설치(**Add python.exe to PATH** 체크)한 뒤, 이 폴더를 복사하고 `setup.bat`을 실행합니다.
  - `.venv`, `작업`, `build`, `dist` 폴더는 빼도 됩니다. `models` 폴더(약 1GB)는 꼭 같이 가져가세요(MeloTTS 모델은 내려받을 수 없음).
  - FFmpeg(`tools\ffmpeg`)는 빼면 setup.bat이 내려받습니다(약 200MB).
- **GitHub에서 받기**: `git clone https://github.com/4leaf321-nox321/MovieEditor.git` 후 `setup.bat`을 실행합니다.
  - 저장소에는 코드만 있습니다(모델·FFmpeg·exe 없음). Supertonic 모델은 처음 실행할 때 내려받고, MeloTTS를 쓰려면 이 PC의 `models\melotts-ko` 폴더를 같은 자리에 복사해 넣으세요.

### exe 버전 다시 만들기
코드를 고친 뒤에는 이렇게 다시 만듭니다(몇 분 걸림).

```bat
.venv\Scripts\python -m pip install -r requirements-build.txt   :: 처음 한 번만
.venv\Scripts\python build.py                                   :: dist\동영상편집기\ 와 dist\동영상편집기.zip
```

## 작업 흐름

1. **①** 대본을 입력하고 **음성 만들기**(Ctrl+Enter) → 들어 보고 **영상 만들기로 →**.
   음성과 자막이 `작업` 폴더에 저장되고, ② 탭에 문장마다 빈 장면이 생깁니다. ③ 탭에도 음성과 자막이 함께 들어갑니다.
2. **②** 빈 장면에 이미지나 영상을 끌어다 놓고, 필요하면 글자 화면을 넣은 뒤 **합성으로 →**(Ctrl+Enter).
3. **③** 자막 모양을 확인하고 **합성하기**(Ctrl+Enter) → 저장할 곳을 고르면 완성입니다.

각 탭은 따로 써도 됩니다. 예를 들어 가진 영상에 음성만 입히려면 ③ 탭만 쓰면 됩니다.

## ① 음성 만들기

1. 글을 입력하거나 붙여넣습니다. TXT 파일을 열거나 편집기에 끌어다 놓아도 됩니다.
   - 줄바꿈은 문장 구분, 빈 줄은 문단 구분(조금 더 길게 쉼)으로 처리합니다.
   - 편집기 오른쪽에 줄마다 읽는 데 걸리는 시간이, 위쪽에 전체 길이가 나옵니다.
2. 오른쪽에서 목소리, 속도, 높낮이, 볼륨, 쉼 길이를 고릅니다. **들어보기**는 짧은 문장, **미리듣기**는 선택한 부분(없으면 앞부분 약 150자)만 만들어 들려줍니다.
3. **음성 만들기**로 전체를 만들고, **영상 만들기로 →** 로 넘기거나 **저장하기**(Ctrl+S)로 파일로 저장합니다.

음성 모델은 이 탭을 처음 열 때 불러옵니다(몇 초). 영상 작업만 할 때는 불러오지 않습니다.

- **쉼 넣기**: 글 중간에 `[쉼 2초]`를 쓰면 그 자리에 정확히 2초 쉽니다(`[쉼]`은 1초, 최대 60초, `[pause 2s]`도 됨). 쉼 표시는 자막에 나오지 않습니다.
- **줄마다 걸리는 시간**: 글이나 설정을 바꾸면 바로 다시 계산합니다. Supertonic은 예상이 실제와 같고, MeloTTS는 2% 안팎 차이가 납니다.
- **목소리 만들기**: 두 목소리를 비율대로 섞어 저장하거나(목록에 ★), Supertonic 3용 목소리 파일(`.json`)을 가져옵니다. `voices` 폴더에 저장됩니다.
- **MeloTTS**: 한국어 전용입니다. 처음 고르면 5–15초 동안 불러옵니다. "품질" 설정은 쓰이지 않습니다.

## ② 영상 만들기

### 장면 만들기
- **음성에 맞추기**: 음성의 문장마다 장면 하나를 만들고, 장면 길이를 그 문장이 끝나고 다음 문장이 시작될 때까지로 맞춥니다. **장면마다 N 문장**으로 여러 문장을 한 장면에 묶을 수 있습니다.
  - 이미 넣어 둔 그림은 순서대로 유지하고 길이만 다시 맞춥니다. 문장이 더 많으면 빈 장면을 더합니다.
  - ①에서 보낸 음성 말고 다른 음성을 쓰려면 **음성 고르기**로 고릅니다. 같은 이름의 SRT가 옆에 있어야 합니다.
- **+ 이미지 / + 영상**: 여러 개를 한 번에 고르면 빈 장면을 차례로 채우고, 남는 것은 뒤에 붙입니다. 파일을 타임라인에 끌어다 놓아도 됩니다. 특정 장면 위에 놓으면 그 장면의 그림이 바뀝니다.
- **+ 글자 화면**: 제목, 챕터, 마무리 인사 같은 장면을 지금 장면 뒤에 넣습니다.
- **● 화면 녹화**: 화면의 원하는 영역을 녹화해서 장면으로 넣습니다.
  1. 프로그램 창이 내려가고 모든 모니터가 어두워지면, 녹화할 영역을 끌어서 고릅니다. **Shift**를 누른 채 끌면 영상 비율(16:9 등)이 유지되고, **Enter**는 그 모니터 전체, **Esc**는 취소입니다.
  2. **● 녹화 시작**(또는 영역 더블클릭)을 누르면 3초 뒤 녹화가 시작됩니다. 영역 둘레의 빨간 테두리와 시간·**■ 정지** 조종판은 녹화에 찍히지 않습니다.
  3. 정지하면 `동영상\동영상 편집기 녹화` 폴더에 MP4로 저장되고, 지금 장면이 빈 장면이면 그 자리를(길이·나레이션 유지), 아니면 바로 뒤에 새 장면으로 들어갑니다.
  - 초당 30프레임, 마우스 포인터 포함. 영역을 고른 뒤 버튼 옆에서 **마이크**, **컴퓨터 소리**(스피커로 나오는 소리)를 켜면 소리도 녹음합니다. 소리는 화면과 시간을 맞춰 합쳐지고, 녹화한 장면은 **클립 소리 넣기**가 켜진 채로 들어갑니다.
  - 저작권 보호가 걸린 화면(넷플릭스 등)은 검게 나옵니다. 원격 데스크톱에서는 쓸 수 없습니다.
- ◀ ▶·복제·삭제로 정리합니다. 순서를 바꾼 뒤 **음성에 맞추기**를 다시 누르면 길이가 문장에 맞춰집니다.
- **↶ ↷ 실행 취소·다시 실행**(Ctrl+Z, Ctrl+Y): 장면·설정·자막 고치기를 모두 되돌립니다. 글자를 연달아 치거나 슬라이더를 움직인 것은 한 번에 되돌아갑니다. **새로 만들기**·**열기**도 되돌릴 수 있습니다.
- **✂ 나누기**(Ctrl+B): 빨간 선 위치에서 장면을 둘로 나눕니다. 클립은 이어지는 구간으로, 이미지는 확대·이동이 끊기지 않게 나뉩니다.
- **+ 효과음**: 빨간 선 위치에 짧은 소리를 넣습니다. 기본 효과음 9가지(띵, 딩동, 뽁, 휙, 뾰로롱, 딸깍, 짠!, 삐빅, 쿵)는 프로그램이 직접 만든 소리라 저작권 걱정 없이 쓸 수 있고(`효과음` 폴더에 만들어 둠), **들어보기**로 미리 들을 수 있습니다. **파일에서 고르기**로 가진 소리(MP3, WAV 등)도 넣고, 소리 파일을 타임라인에 끌어다 놓으면 놓은 자리에 들어갑니다. ▶ 재생에 들리고, **합성으로 →**를 누르면 ③ 탭에서 함께 넣습니다(③에서 끌 수 있음).

### 여러 장면 고르기와 단축키
- **Ctrl+클릭**으로 하나씩 더하거나 빼고, **Shift+클릭**으로 사이를 모두 고릅니다(**Ctrl+A**: 모두).
- 고른 장면은 함께 끌어 옮기고, 복사·잘라내기·붙여넣기·복제·삭제할 수 있습니다. 장면을 오른쪽 클릭해도 메뉴가 나옵니다.
- 여러 장면을 고른 채 **장면**·**보정** 탭에서 값을 바꾸면 고른 장면 모두에 적용됩니다(길이, 맞춤, 움직임, 전환, 색 보정 등. 파일·구간·글자 내용은 지금 장면만).

| 키 | 하는 일 | 키 | 하는 일 |
|---|---|---|---|
| Space | 재생 / 멈춤 | Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| ← → | 한 프레임 이동 | Shift+← → | 1초 이동 |
| ↑ ↓ | 이전 / 다음 장면 | Home / End | 처음 / 끝 |
| Ctrl+C / X / V | 장면 복사 / 잘라내기 / 붙여넣기 | Ctrl+D | 복제 |
| Delete | 고른 장면 삭제 | Ctrl+B | 빨간 선에서 나누기 |
| Esc | 재생을 멈추고 장면 보기 | Ctrl+S / Ctrl+O | 프로젝트 저장 / 이미지 추가 |

화살표·Delete·복사·붙여넣기는 미리보기나 타임라인을 누른 뒤에 듣습니다(오른쪽 설정 칸에서는 그 칸의 키로 쓰입니다). 탐색기에서 복사한 이미지·영상 파일도 Ctrl+V로 넣을 수 있습니다.

### 타임라인 (화면 아래)
모든 장면이 시간 길이만큼 이어져 보입니다.

| 줄 | 보이는 것 | 조작 |
|---|---|---|
| 눈금 | 시간 | 누르거나 끌면 그 순간이 미리보기에 나옵니다(빨간 선) |
| 장면 | 이미지는 설정한 길이만큼, 클립은 실제로 재생되는 화면. 클립에는 배속, **멈춤**(빗금), 반복(점선), **뒤 잘림** 표시가 붙습니다. 장면 사이의 ◆는 전환 효과, 아래 왼쪽의 **글자·겹침** 표시는 올린 것이 있다는 뜻입니다 | 누르면 선택. **오른쪽 끝**을 끌면 길이가 바뀌고, 음성 문장 경계 근처에서는 거기에 붙습니다(Shift를 누르면 자유롭게). **가운데**를 끌면 순서가 바뀝니다 |
| 클립 구간 | 클립마다 그 아래에, 클립 전체와 쓰는 구간(파란 손잡이 사이) | 손잡이를 끌면 구간이 바뀌고, 끄는 동안 그 순간이 미리보기에 나옵니다 |
| 음성·자막 | 음성 파형과 자막 줄마다의 위치·내용 | 자막을 **두 번 누르면** 문구와 시간을 고치고, **양 끝을 끌면** 시간이 바뀝니다. 오른쪽 클릭으로 지우기 |
| 효과음 | 넣은 효과음마다 파형과 이름 | **끌어서** 옮기면 장면·문장 시작에 붙습니다(Shift: 자유롭게). **두 번 누르면** 들어보기, 오른쪽 클릭으로 크기·빨간 선으로 옮기기·지우기. 빈 곳을 오른쪽 클릭하면 그 자리에 넣습니다 |
| 배경 음악 | 음악 파형. 목소리가 나올 때 줄어드는 부분, 처음·끝 페이드가 보입니다 | 누르면 음악 설정이 열립니다 |

- Ctrl+휠로 확대·축소, 휠로 좌우 이동, **맞춤**으로 전체 보기. 마우스를 올리면 장면·구간·문장 정보가 나옵니다.
- 고친 자막은 프로젝트에 저장되고(음성의 SRT 파일은 그대로), 미리보기와 **합성으로 →**에 쓰입니다. **전체** 탭의 **자막을 원래대로**로 되돌립니다.

### 설정 탭 (미리보기 오른쪽)
**장면** 탭
| 항목 | 설명 |
|---|---|
| 맞춤 | **꽉 채우기**: 화면을 채우고 가장자리를 자름. **전체 보이기**: 그림 전체를 보이고 빈 곳은 흐린 배경. 화면과 모양이 많이 다른 그림(가로 사진을 세로 쇼츠에 넣을 때 등)은 처음부터 전체 보이기로 들어갑니다 |
| 움직임 (이미지) | 천천히 확대·축소, 왼쪽↔오른쪽 이동, 없음 |
| 구간 (영상 클립) | 쓸 부분의 시작~끝을 숫자로 정확히 넣습니다(타임라인의 클립 구간 손잡이와 같음). **전체**는 클립 전체 |
| 속도 (영상 클립) | 0.1–8배속. 0.5배속은 느리게 2배 길이로, 2배속은 빠르게 절반 길이로 재생합니다. 클립 소리는 음 높이를 유지한 채 같이 빨라지거나 느려집니다 |
| 짧으면 (영상 클립) | 클립이 장면보다 짧을 때: **마지막 화면에서 멈춤**, **처음부터 반복**, **속도를 바꿔 장면에 꽉 맞춤**(음성 문장 길이에 클립을 딱 맞출 때). 길면 장면 끝에서 잘립니다. 아래 안내 문구에 결과가 미리 나옵니다 |
| 장면 길이를 클립에 맞춤 | 반대로, 고른 구간을 지금 속도로 재생한 길이만큼 장면 길이를 바꿉니다 |
| 방향 (영상 클립) | **거꾸로 재생**: 고른 구간을 끝에서부터 거꾸로 보여 줍니다(클립 소리도 거꾸로) |
| 클립 소리 | **넣기**를 켜면 클립의 소리가 들어갑니다. **크기**(0–300%)로 클립마다 소리 크기를 정하고, 전체 크기는 ③ 탭의 **원본 소리**로 정합니다 |
| 배경 (글자 화면) | 단색 또는 위→아래 그라데이션 |
| 다음 전환 | 이 장면에서 다음 장면으로 넘어가는 방법과 시간. **영상 설정을 따름**이면 위의 **장면 전환** 설정을 씁니다 |

**글자** 탭: 한 장면에 글자를 여러 개 넣을 수 있습니다. 글자마다 글꼴·크기·색·위치(위·가운데·아래 또는 가로·세로 %)를 정하고, **미리보기에서 끌어 옮길** 수 있습니다. **나타남**으로 장면이 시작될 때 서서히 나타남, 톡 튀어나옴, 아래에서 올라옴, 한 글자씩(타자기) 효과를, **사라짐**으로 장면이 끝날 때 서서히 사라짐, 작아지며 사라짐, 아래로 내려가며 사라짐 효과를 줍니다(장면 끝에 맞춰 약 0.5초. 정지 미리보기에는 다 나타난 모습이, ▶ 재생에는 움직임이 나옵니다). 장면을 나누면 나타남은 앞쪽, 사라짐은 뒤쪽에만 남습니다. **이 글자 모양을 모든 장면에 적용**으로 통일합니다.

**움직임 (키프레임)** (글자·겹치기 탭): 글자나 그림이 장면 안에서 움직이게 합니다.
1. 타임라인의 빨간 선을 움직임이 시작될 곳에 두고 **◆ 키프레임**을 누릅니다(지금 자리와 크기를 기억).
2. 빨간 선을 다른 시각으로 옮긴 뒤, 미리보기에서 끌어 옮기면(그림은 휠로 크기도) 그 시각에 키프레임이 생기고, 그 사이를 움직입니다.
3. ◀ ▶로 키프레임 사이를 오가고, **삭제**는 지금 시각의 키프레임을, **모두 지우기**는 움직임을 없앱니다. **천천히 출발·도착**을 끄면 같은 빠르기로 움직입니다.

키프레임이 있으면 위치 칸에는 빨간 선 시각의 자리가 나오고, 고치면 그 시각의 키프레임이 바뀝니다. 겹친 영상도 결과에서 똑같이 움직입니다.

**겹치기** 탭: 장면 위에 **그림**(로고, 스티커, 투명 PNG)이나 **영상**(화면 속 작은 화면)을 올립니다. 크기·불투명도·흰 테두리·위치(모서리 또는 직접)·나타남·사라짐을 정하고, 미리보기에서 끌어 옮기거나 **마우스 휠로 크기**를 바꿉니다. 목록 아래쪽에 있는 것이 위에 그려지고, 글자는 항상 맨 위입니다. 겹친 영상은 소리 없이 정한 위치부터 재생되고, 장면보다 짧으면 마지막 화면에서 멈춥니다(나타남·사라짐은 '서서히'만).
**크로마키**: **이 색을 투명하게**를 켜면 초록 화면 같은 배경색이 빠져 뒤의 장면이 보입니다(그림·영상 모두). 색 버튼의 색 고르기 창에서 **Pick Screen Color**로 미리보기 속 색을 바로 찍을 수 있고, **빼는 범위**가 클수록 비슷한 색까지 더 빠집니다.

**가리기** 탭: 얼굴, 차 번호판, 주소처럼 보이면 안 되는 부분을 **모자이크**나 **흐리게**로 가립니다. 미리보기의 주황 상자를 끌어 옮기고, 모서리를 끌거나 휠을 돌려 크기를 바꾸며, **세기**로 모자이크 칸 크기·흐린 정도를 정합니다. 장면 내내 같은 자리를 가리고, 위에 올린 글자와 그림은 가리지 않습니다. 상자는 이 탭을 열었을 때만 보입니다.

**보정** 탭 (이미지·영상 클립): 회전(90° 단위), 좌우·상하 뒤집기, 가장자리 잘라내기(%), 밝기·대비·채도, 필터(흑백, 세피아, 따뜻하게, 차갑게, 선명하게, 빈티지). 위에 올린 글자와 그림에는 적용되지 않습니다. **모든 장면에 적용**은 색 보정만 모든 이미지·영상 장면에 씁니다.

**그래픽 장면** (장면 탭의 **종류 → 그래픽**): 도형·선·화살표·글자·올라가는 숫자·해석 결과 같은 색 타일·분포 곡선·막대 그래프·소품(선화)을 레이어로 쌓아, 프레임마다 그려지는 설명 애니메이션을 만듭니다. 사진 장면처럼 전환·음성·자막·글자·겹치기와 함께 쓰이고, 미리보기와 결과가 같은 방식으로 그려집니다.
- 레이어마다 위치(화면 비율)·크기·색과 **나타남**(서서히, 그려 나가기, 커지며, 톡, 밀려 들어옴, 닦아내기, 타자기, 숫자 세기, 칸·막대가 차례로), **사라짐**, **키프레임**(위치·크기·투명도·회전이 시간 함수에 따라 움직임)을 정합니다.
- **스타일**은 색 팔레트, 글꼴 역할(title, heading, body, caption, label, number), 배경(그라데이션·비네트·격자·점·잡티), 색 지도, 선·도형·화살표·그림자 기본값, 소품, 움직임(시간 함수, 길이, 간격)을 정한 묶음입니다. 레이어는 색·글꼴·소품을 이름으로 부르므로, 스타일만 바꾸면 같은 장면이 다른 모양으로 그려집니다.
  - 기본 제공: **기본**(어두운 남색, 기술·해석 설명), **밝게**(흰 바탕 발표 자료). **보기**를 누르면 그 스타일의 색·글꼴·배경·소품을 한 장으로 봅니다.
  - 새 스타일은 `스타일` 폴더의 JSON 파일입니다. `base`로 바탕 스타일을 정하면 바꿀 부분만 적으면 되고, 기본 제공 스타일과 같은 이름의 파일을 두면 그 파일이 우선합니다. Claude(MCP)의 **save_style**로 만들게 해도 됩니다.
- 레이어는 **레이어 고치기…**에서 JSON으로 고치거나(저장 전에 이름·색·값을 검사), Claude(MCP)에게 맡깁니다. 항목 설명은 MCP의 **graphic_guide**에 있습니다.
- **식**: 숫자 칸 어디에나 `"0.5 + 0.1*sin(2*pi*t)"`처럼 식을 쓸 수 있습니다(t: 시간, i: 몇 번째, p: 진행 0→1 등). 계산만 되고 다른 코드는 실행되지 않습니다.
- **묶음(group)·반복**: 여러 레이어를 묶어 함께 움직이고(회전·크기·나타남), `count`로 i번째마다 식이 달라지는 여러 개를 만들며, `clip`으로 원·도형·**글자 모양**으로 잘라 보입니다.
- **꾸밈**: 도형·선·글자에 그라데이션, 빛 번짐(glow), 섞기(multiply·screen·overlay 등), 한 줄 안의 글자색·굵기 바꾸기(`[accent]강조[/]`), 한 글자씩 나타나기(솟아오름·떨어짐·톡·회전), 출렁이는 글자.
- **그림 묶음·영상 레이어**: 번호 붙은 PNG 묶음(frames)이나 영상(video, 투명 영상 포함)을 레이어로 얹습니다. 다른 프로그램이나 코드로 만든 그림도 이렇게 넣어 스타일과 함께 씁니다.
- **플러그인**: `플러그인` 폴더에 파이썬 파일 하나를 두면 새 레이어 종류가 됩니다(`draw(painter, api, layer)`; api로 스타일의 색·글꼴·시간 함수를 써서 같은 모양을 유지). 기본으로 입자(particles), 물결(wave), 진행률(progress)이 들어 있고, 파일을 고치면 바로 반영됩니다. 만드는 법은 MCP의 **list_plugins**에 있습니다.

**템플릿**: 제목, 목록, 큰숫자, 막대비교, 해석결과(색 타일), 분포(곡선), 흐름(단계 상자), 결론(강조 문장), 사진설명, 비교(둘 비교) 같은 그래픽 장면의 틀입니다. 타임라인 위 **+ 템플릿**으로 새 장면을, 그래픽 장면의 **템플릿에서…**로 지금 장면의 그림을 만듭니다. 틀을 고르고 빈칸(제목, 값, 항목 등)만 채우면 미리보기가 바로 보이고, 스타일의 색·글꼴을 따르므로 어느 스타일에서나 어울립니다. 자주 쓰는 장면은 Claude(MCP)로 새 템플릿을 만들어 `템플릿` 폴더에 쌓아 둘 수 있습니다.

**콘티 엑셀** (**프로젝트 ▾** 메뉴)
- **콘티 엑셀에서 만들기**: 줄마다 장면 하나를 만듭니다. 머리글 이름으로 열을 알아보므로(나레이션·대사·멘트·스크립트, 화면설명·연출, 소스·자료·파일, 템플릿, 템플릿 값, 길이·시간·초, 화면 글자·자막 …) 쓰던 양식 그대로 됩니다. 소스가 있으면 그 이미지·영상(엑셀과 같은 폴더나 그 안의 `소스` 폴더 기준), 템플릿이 있으면 그 그래픽 장면(템플릿 값 칸: `title=제목; items=가 | 나 | 다`), 화면 글자만 있으면 제목 화면, 아무것도 없으면 빈 장면이 됩니다. 음성이 있으면 장면 길이를 그 음성에 맞출지 묻습니다.
- **콘티 엑셀로 내보내기**: 장면마다 썸네일·시작·끝·길이·나레이션·종류·소스·화면 글자를 넣은 콘티와, **소스목록** 시트(쓴 파일, 쓰인 장면, 출처·라이선스 빈칸), 음성이 있으면 **나레이션 비교** 시트(대본과 실제 음성의 다른 곳을 빨강·파랑으로 표시)를 만듭니다.
- **스토리보드 그림 저장**(JPG·PNG 한 장), **장면 그림 모두 저장**(장면마다 원본 크기 PNG), **빈 콘티 양식 만들기**(열·예시·도움말 시트).
- 콘티의 나레이션을 대본으로 음성을 만들면(나레이션 없는 줄은 그 길이만큼 쉼), 장면이 음성의 그 문장에서 정확히 바뀝니다. 이 흐름은 Claude(MCP)에게 맡기면 한 번에 됩니다.

**전체** 탭 (영상 전체)
- **시작·끝 페이드**: 영상이 검은 화면에서 서서히 밝아지며 시작하고, 끝에서 서서히 어두워집니다. 소리도 같이 커지고 작아집니다. **합성으로 →**를 누르면 ③ 탭에 넘어가 음성·음악까지 함께 페이드됩니다.
- **배경 음악**: 길이가 모자라면 반복합니다. 크기, **목소리가 나올 때 음악을 줄임**(말하는 동안 약 10dB 작아지고 쉬는 동안 돌아옴), 처음·끝 **페이드**. ▶ 재생에도 들어가고, **합성으로 →**를 누르면 ③ 탭에 설정째 넘어갑니다.
- **로고·워터마크**: 그림을 네 모서리 중 한 곳에 영상 내내 띄웁니다. 크기와 불투명도를 정합니다.

### 그 밖
- **화면**: 가로 16:9(1080p, 4K, 720p), 세로 9:16 쇼츠(1080p, 4K), 정사각 1:1. 글자 크기는 화면 크기에 비례합니다.
  - 4K는 만드는 데 1080p의 약 4배가 걸립니다(12초 영상 기준 6.6초 → 24.5초). ③ 합성 탭은 받은 영상의 해상도를 그대로 유지합니다.
  - 확대·이동이 끝까지 선명하려면 이미지가 화면보다 15% 이상 커야 합니다(1080p는 가로 2200px, 4K는 4400px 정도).
- **초당 프레임**: 24(영화 느낌), 25, 30(기본), 50, 60(부드러움). 게임·화면 녹화처럼 빠른 움직임은 60이 부드럽지만, 만드는 시간과 파일 크기가 늘어납니다. 클립은 이 빠르기에 맞춰 바뀌고, **화면 녹화**도 50·60이면 그 빠르기로 녹화합니다.
- **파일로 저장**: 음성·자막 없이 장면만 이어 붙인 영상을 저장합니다. 저장 창의 **파일 형식**에서 MP4(H.264·H.265), MOV, MKV, WebM, GIF 움짤을 고를 수 있습니다.
- **장면 전환**: 부드럽게 겹치기, 검은·흰 화면 거치기, 점점이 바뀜, 옆·위로 밀어내기, 닦아내기, 부드럽게 닦기, 원형으로 열기, 시계 방향으로, 확대하며 바뀜, 모자이크, 흐려지며 바뀜, 없음. 새 장면은 그 문장이 시작될 때 나타나기 시작합니다. 장면마다 다르게 하려면 **장면** 탭의 **다음 전환**을 씁니다.
- **그래픽 카드로 인코딩**: NVIDIA·Intel·AMD 그래픽 카드의 인코더로 영상을 만듭니다(②③ 탭 공통). 인코딩만 놓고 보면 약 2배 빠르지만(RTX 3070, 4K), 장면 그리기와 디코딩 시간은 그대로라 전체로는 10–30% 빨라지고 파일은 1.5–2배 커집니다. 쓸 수 없는 PC에서는 CPU로 만듭니다.
- **미리보기**: 타임라인의 빨간 선 위치를 보여 줍니다. 확대·이동이 어떻게 움직이는지 눈금을 끌며 볼 수 있습니다. 결과와 같은 방식, 같은 해상도로 그립니다. 로고도 같이 나옵니다.
  **원본 크기로 보기**(또는 미리보기를 두 번 클릭)를 누르면 실제 픽셀 그대로 보는 창이 열리고, 끌어서 둘러볼 수 있습니다. **이미지로 저장**은 그 순간을 원본 크기 PNG·JPG로 저장합니다(썸네일). ③ 탭의 미리보기도 같습니다.
- **▶ 재생**(Space): 빨간 선 위치부터 음성·자막·배경 음악과 함께 재생합니다. 자막은 ③ 탭에서 정한 모양으로 나옵니다. 빨리 만들 수 있도록 작게(가로 960) 만든 미리보기 영상을 씁니다.
  - 처음엔 몇 초 걸리고(15초 영상 기준 약 4초), 바뀐 게 없으면 바로, 한 장면만 고쳤으면 그 장면만 다시 만듭니다(약 3초).
  - 재생 중에는 빨간 선이 따라가고, 타임라인을 누르면 그곳으로 건너뜁니다. **멈추고 장면 보기**(Esc)를 누르면 멈춘 곳의 장면이 선택됩니다.
  - 다른 탭으로 가면 재생이 멈춥니다.
- **프로젝트 ▾**: 장면 목록을 `.json`으로 저장하고 다시 열 수 있습니다. 예전 버전에서 저장한 프로젝트도 그대로 열립니다.
- **자동 저장**: 장면은 고칠 때마다(1.5초 뒤) `작업\마지막 장면.json`에, ① 탭의 대본은 `작업\대본.txt`에 저장되어 다음 실행 때 그대로 열립니다. 프로그램이 갑자기 꺼져도 몇 초 전 상태까지 남고, 다음에 켜면 "제대로 닫히지 않았다"는 안내와 함께 불러옵니다.
  - 켤 때, 닫을 때, 작업 중 5분마다 날짜가 붙은 사본을 `작업\자동저장`에 남깁니다(종류마다 최근 20개). 실수로 **새로 만들기**를 했거나 예전 상태로 돌아가고 싶으면 **프로젝트 ▾ → 자동 저장 기록에서 열기**를 쓰세요.
  - 프로그램을 두 개 띄우면 나중에 켠 쪽은 `마지막 장면_창번호.json`에 따로 저장해서, 서로 덮어쓰지 않습니다.
- 장면마다 만든 영상 조각은 `작업\장면캐시`에 남겨 두어서, 한 장면만 고치면 그 장면만 다시 만듭니다.

## ③ 영상-음성-자막 합성하기

1. **영상**, **음성**, **자막**을 고릅니다(①②에서 넘어오면 자동으로 채워짐). 창에 끌어다 놓아도 됩니다.
2. 길이·소리·자막 모양을 정합니다. 미리보기는 실제 결과와 같은 엔진(libass)으로 그립니다.
3. **합성하기**를 누르고 저장할 곳을 고릅니다. 저장 창의 **파일 형식**에서 MP4(H.264, 어디서나 재생), MP4(H.265, 파일이 작음), MOV, MKV, WebM, GIF 움짤(소리 없음, 자막은 그림에 입힘), MP3·WAV(소리만)를 고를 수 있고, 마지막에 고른 형식을 기억합니다.

| 항목 | 설명 |
|---|---|
| 결과 길이 | **음성 길이에 맞춤**: 음성 시작 + 음성 길이 + 끝 여백. **영상 길이에 맞춤**: 원본 영상 길이 |
| 영상이 짧으면 | **마지막 장면에서 멈춤** 또는 **처음부터 반복** |
| 음성 시작 | 음성을 몇 초 뒤에 시작할지. 자막도 같이 이동합니다 |
| 원본 소리 | 영상에 원래 있던 소리 크기(② 클립 소리 포함). 0%면 뺍니다 |
| 배경 음악 | **파일**의 **배경 음악**에 고르면 결과 길이만큼 반복해 깝니다. 크기, 목소리 나올 때 줄이기, 페이드. ②에서 음악을 정했으면 함께 넘어옵니다 |
| 효과음 | ②에서 넣은 효과음이 함께 넘어오면 나타납니다. 끄면 빼고 만듭니다 |
| 시작·끝 페이드 | 결과가 검은 화면·무음에서 서서히 시작하고 끝납니다. ②에서 정했으면 함께 넘어옵니다 |
| 음량 맞추기 | 결과 소리의 크기를 기준(유튜브·SNS -14 LUFS, 팟캐스트 -16, 방송 -24)에 맞춥니다. 소리를 먼저 한 번 재고 맞추므로 조금 더 걸립니다. 유튜브 등은 기준보다 크면 알아서 줄이므로, 맞춰 두면 다른 영상과 크기가 비슷해집니다 |
| 자막 방식 | **영상에 입히기**: 어디서든 보임. **켜고 끄는 자막**: 빠르지만 플레이어에서 켜야 보임 |
| 단어 강조 | **읽는 만큼 색 채우기**(노래방처럼), **지금 읽는 단어만** 강조 색으로. 단어마다의 시간은 자막 한 줄의 시간을 글자 수로 나눠 짐작합니다 |
| 나타남 | 자막이 나올 때 서서히 나타남, 톡 튀어나옴, 아래에서 올라옴 |
| 그래픽 카드로 인코딩 | ② 탭과 같은 설정입니다 |

미리보기의 **이미지로 저장**은 자막까지 입힌 그 장면을 원본 크기로 저장합니다(썸네일).

## Claude에서 쓰기 (MCP)

이 편집기를 Claude Code와 Claude Desktop의 **MCP 서버**로 연결해 두었습니다. 편집기 창을 켜지 않아도 Claude에게 말로 시키면 음성 만들기부터 장면 구성, 최종 영상까지 만듭니다.

> 이 대본으로 세로 쇼츠 만들어 줘. 장면마다 `D:\사진`의 이미지를 차례로 넣고, 첫 장면에 제목 "오늘의 소식"을 크게, 유튜브 음량에 맞춰서.

Claude는 보통 이 순서로 도구를 씁니다.
1. **make_voice**: 대본을 음성(MP3)과 자막(SRT)으로 만듭니다(목소리는 **list_voices**).
2. **new_project**: 음성의 문장마다 빈 장면을 만들고 길이를 문장에 맞춥니다.
3. **fill_scenes**·**update_scene**·**add_scenes**: 그림·영상·글자·겹치기·가리기·키프레임·보정을 넣습니다. **update_project**로 화면 비율, fps, 전환, 페이드, 배경 음악, 로고, 효과음을 정합니다.
4. **preview_frame**: 원하는 순간의 화면을 그림으로 보고 확인합니다(결과와 같은 방식으로 그림). **export_frame**은 원본 크기 썸네일을 저장합니다.
5. **render_video**: 장면 + 음성 + 자막 + 음악 + 효과음을 넣은 최종 영상을 만듭니다. 형식(MP4, H.265, MOV, MKV, WebM, GIF, MP3, WAV)과 음량 맞추기를 고를 수 있고, 자막 모양은 ③ 탭에 저장된 모양을 씁니다.

설명 그림은 **그래픽 장면**(kind "graphic")으로 만듭니다. Claude는 직접 그리기 코드(Pillow, MoviePy 등)를 짜지 않고 이 도구의 레이어와 스타일로 만들도록 안내받습니다.
- **graphic_guide**: 레이어 종류·항목·나타남·시간 함수 설명. **list_styles**·**get_style**·**style_sheet**(스타일 한 장 그림): 있는 스타일 보기. **save_style**·**delete_style**: 스타일 만들기·고치기·지우기.
- **preview_frames**: 한 장면의 여러 순간을 한 장으로 보여 줘서, 나타남·움직임을 Claude가 직접 확인합니다.
- **list_plugins**: 플러그인 목록과 새 플러그인 만드는 법. 레이어로 안 되는 그림은 ① 플러그인(없으면 Claude Code가 플러그인 폴더에 만들어 두고 계속 씀) ② 코드로 만든 PNG 묶음·투명 영상을 frames·video 레이어로 넣기, 순서로 하도록 안내되어 있습니다.
- 기존에 쓰던 스타일을 옮길 때는, 색(#rrggbb)·글꼴·배경·자주 쓰는 소품 모양을 알려 주면 Claude가 save_style로 스타일 파일을 만듭니다.

**콘티 엑셀에서 영상까지**: read_storyboard(열 확인) → storyboard_script(대본) → make_voice → storyboard_to_project(음성에 맞춤) → render_video. 그 밖에 **project_to_storyboard**(썸네일 콘티·소스목록·나레이션 비교 엑셀), **compare_narration**(대본·콘티·프로젝트와 실제 음성 비교), **storyboard_image**(스토리보드 JPG), **export_keyframes**(장면 PNG), **new_storyboard**(빈 양식). 템플릿은 **list_templates**·**preview_template**·**apply_template**(빈칸 채워 장면 넣기·바꾸기), **save_template**·**scene_to_template**(만든 장면을 틀로)·**get_template**·**delete_template**.

그 밖에 **compose**(이미 있는 영상에 음성·자막·음악 입히기, ③ 탭과 같음), **media_info**, **get_project**, **remove_scenes**, **move_scene**, **fit_to_voice**, **list_sound_effects**, **field_guide**(넣을 수 있는 항목 설명)가 있습니다.

- 오래 걸리는 일(음성 만들기, 영상 만들기, 합성)은 한 번에 하나씩 차례로 합니다. 40초 안에 끝나지 않으면 Claude가 **job_status**로 이어서 기다리고, **cancel_job**으로 취소합니다.
- 결과와 프로젝트는 따로 정하지 않으면 `작업\MCP`에 저장됩니다. 프로젝트(`.json`)는 편집기 ② 탭의 **프로젝트 ▾ → 열기**로 열어 손볼 수 있고, 편집기에서 저장한 프로젝트를 Claude에게 고치게 할 수도 있습니다.
- 장면 캐시는 편집기와 따로(`작업\장면캐시_MCP`) 써서, 편집기를 켜 둔 채 같이 써도 서로 방해하지 않습니다. 그래픽 카드 인코딩은 편집기의 설정을 따릅니다.
- **연결 설정**: Claude Code는 사용자 설정(`%USERPROFILE%\.claude.json`, 모든 폴더에서 쓰임)에, Claude Desktop은 `%APPDATA%\Claude\claude_desktop_config.json`에 `movie-editor`로 들어 있습니다. 둘 다 이 PC의 `.venv\Scripts\python.exe mcp_server.py`를 실행합니다. Claude Desktop은 설정을 바꾼 뒤 트레이에서 완전히 종료하고 다시 켜야 불러옵니다.
  - 다시 등록: `claude mcp add --scope user movie-editor -- "<폴더>\.venv\Scripts\python.exe" "<폴더>\mcp_server.py"` / 빼기: `claude mcp remove movie-editor -s user`
  - **exe 버전**은 같은 폴더의 `movie-mcp.exe`가 MCP 서버입니다: `claude mcp add --scope user movie-editor -- "<exe 폴더>\movie-mcp.exe"`, Claude Desktop 설정에는 `"command": "<exe 폴더>\movie-mcp.exe"`(args 없음)로 넣습니다. 프로그램을 쓰지 않을 때도 Claude가 알아서 켜고 끕니다.

## 명령줄

```bat
:: 합성 (③ 탭과 같은 기능)
.venv\Scripts\python cli.py 영상.mp4 음성.mp3                     :: 음성.mp4 (음성.srt가 있으면 자막도)
.venv\Scripts\python cli.py 영상.mp4 음성.mp3 --extend loop --original-volume 20 -o 결과.mp4
.venv\Scripts\python cli.py -h

:: 음성 만들기 (① 탭과 같은 기능)
.venv\Scripts\python tts_cli.py 원고.txt --srt                    :: 원고.mp3 + 원고.srt
.venv\Scripts\python tts_cli.py --list-voices
```

| `템플릿/` | 내가 만든 장면 템플릿 (JSON) |
| `settings.ini`, `error.log` | 설정(탭별 구역 `[tts]`, `[scenes]`, `[compose]`, 공통 `gpu`), 오류 기록 |

## 알아 둘 점

- 숫자, 영어 약어, 특수기호를 어색하게 읽으면 글에서 한글로 풀어 쓰세요(예: `3,500원` → `삼천오백 원`).
- 오류가 나면 `error.log`에 자세한 내용이 남습니다.
- 라이선스: 개인 용도로는 문제없습니다. 배포할 일이 생기면 Supertonic(OpenRAIL-M/MIT), MeloTTS(MIT), pedalboard(GPLv3), FFmpeg(GPL) 라이선스를 확인하세요.
